# App Deep-Link Routing (`/app/<slug>`) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make an app shareable via `/app/<slug>` — selecting an app navigates to that path (push history); opening the URL loads the full catalog with the app's detail open. Replaces the `?app=<slug>` query param.

**Architecture:** Add a tanstack file-route `routes/_layout/app.$slug.tsx` that renders the existing `AppCatalogLayout` + `AppCatalogPage`, passing the path `$slug` as the selected app. `AppCatalogPage` stops owning the app selection via `useUrlSyncedState` and instead takes the selected slug as a prop and navigates on select/clear. The `app` search param is removed from the index route.

**Tech Stack:** React, TanStack Router (file-based, auto-generated `routeTree.gen.ts` via `@tanstack/router-plugin/vite`), Vitest + Testing Library integration harness (`src/__tests__/integration/harness/given.tsx`).

## Global Constraints

- Repo: `app-catalog` (open source), package `packages/frontend-core`. All paths below are relative to `packages/frontend-core/`.
- Commits are **GPG-signed**; if signing prompts for a PIN, wait for it — never `--no-gpg-sign`.
- Do not edit `src/routeTree.gen.ts` by hand — it is regenerated by the vite plugin on build/dev.
- Run checks from `packages/frontend-core`: `pnpm exec vitest run <file>`, `pnpm exec tsc --noEmit`, `pnpm exec eslint <files> --max-warnings=0`.
- Frontend integration tests use the `given()` harness; its `ui` API (`ui.catalog.openApp(name)`, `ui.catalog.isDetailPanelOpen()`, `ui.catalog.getTableData()`) and `createMemoryHistory({ initialEntries: [...] })` drive routing. See the `frontend-test-writer` skill.
- The live detail panel is rendered by `AppCatalogGrid` (receives `selectedAppSlug` + `onAppClick`). `AppDetailModal` no longer exists.

- [ ] **Step 5: Create the route**

Create `src/routes/_layout/app.$slug.tsx`:

```tsx
import { createFileRoute } from '@tanstack/react-router'
import { appCatalogRouteLoader } from '~/modules/appCatalog/routeLoader'
import { AppCatalogLayout } from '~/modules/appCatalog/ui/layout/AppCatalogLayout'
import { AppCatalogPage } from '~/modules/appCatalog/ui/pages/AppCatalogPage'

export const Route = createFileRoute('/_layout/app/$slug')({
  component: RouteComponent,
  async loader() {
    const appCatalogLoader = await appCatalogRouteLoader()
    return { appCatalogLoader }
  },
})

function RouteComponent() {
  const { queryClient, trpcClient } = Route.useRouteContext()
  const { slug } = Route.useParams()

  return (
    <AppCatalogLayout queryClient={queryClient} trpcClient={trpcClient}>
      <AppCatalogPage selectedSlug={slug} />
    </AppCatalogLayout>
  )
}
```
